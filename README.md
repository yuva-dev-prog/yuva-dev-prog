## 🚀 Featured Project

### 🎓 [AI College Information Assistant](https://github.com/yuva-dev-prog/ragchatbot)

A full-stack assistant that answers questions using college documents. It combines document processing, semantic and keyword search, conversational context, and answers with source citations.

**Highlights**

- 📄 Ingests PDF, DOCX, and TXT documents
- 🔍 Combines semantic retrieval with keyword search
- 💬 Supports follow-up questions across a conversation
- 📚 Provides source citations with document and page details
